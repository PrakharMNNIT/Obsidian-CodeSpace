# Code Space 发布说明 - 1.7.0

## 概览
这个版本改进了编辑器内的查找替换流程，增强了代码嵌入的稳定性（包括弹出窗口），并更新了文档与界面文案。

## 代码编辑器查找与替换
- 在 Code Space 编辑器中会拦截 `Ctrl/Cmd+F`，改为打开自定义搜索面板（支持切换开关）。
- `Ctrl+H`（macOS 上为 `Cmd+Alt+F`）会直接聚焦替换输入框。
- 打开搜索面板时，可自动将当前选中文本填入搜索词。
- 替换支持空字符串，可用于删除型工作流。
- 针对移动端输入行为进行了调整，以减少键盘遮挡问题。

## 代码嵌入稳定性与弹出窗口
- 在笔记切换期间，嵌入渲染更加稳定，可减少短暂显示错误文件的情况。
- 弹出窗口现在会安装独立的嵌入处理逻辑，确保代码嵌入能可靠渲染。
- 弹出窗口会继承 Code Space 的嵌入样式和主题状态，保持布局一致。
- 行数标记与行数限制滚动在弹出窗口嵌入中已恢复。
- 即使 vault 中其他位置存在同名文件，像 `![[foo.ts]]` 这样的显式根路径引用也能正确解析。
