# Code Space 发布说明 - 2.3.0

## 概览

Code Space 2.3.0 是面向 Obsidian 社区插件审核的发布准备版本。本次更新让插件声明的最低 Obsidian 版本与实际使用的 API 保持一致，同时清理 popout 窗口兼容性相关的源码写法，并调整样式表以通过更严格的审核 lint 检查。

本版本不改变 Code Space 编辑器、Dashboard、代码嵌入或大纲视图的既有工作流。主要的运行要求变化是：插件现在准确声明最低支持 Obsidian `1.7.2`。

## 改进

### 准确的 Obsidian 兼容性元数据

插件元数据现在与 Code Space 实际使用的 Obsidian API 保持一致。

- `manifest.json` 将 `minAppVersion` 声明为 `1.7.2`。
- `versions.json` 将已发布插件版本映射到同一最低应用版本，以满足目录校验。
- 发布元数据不再声称支持缺少 `Workspace.revealLeaf` 等 API 的旧版 Obsidian。

### popout 与窗口兼容性清理

多个源码层面的审核警告已经处理，并且不改变面向用户的功能行为。

- 需要访问文档对象的位置改为使用 Obsidian 兼容的 document 引用。
- 定时器与动画调度方式符合当前 Obsidian lint 预期。
- 适用位置已改用推荐的 `createDiv` 与 `createSpan` DOM helper。
- 清理了未使用参数和不安全数组类型相关警告。

### 样式表 lint 清理

样式表已按 Obsidian CSS 审核警告进行调整，同时保留原有显示效果。

- 合并了重复选择器。
- 移除了多处 `!important`，改用已有选择器优先级。
- 将部分兼容性受限的 CSS 特性替换为更适合审核的写法。
- 修正了 lint 标记的十六进制颜色简写格式。

## 重要说明

- 最低支持 Obsidian 版本现在是 `1.7.2`。
- 不需要迁移设置。
- 没有移除命令、文件关联或 Dashboard 操作。
- 发布资产仍为 `main.js`、`manifest.json` 和 `styles.css`。
