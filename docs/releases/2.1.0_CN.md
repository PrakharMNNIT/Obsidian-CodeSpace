# Code Space 发布说明 - 2.1.0

## 概览

2.1.0 是个偏小的版本，主要补几处编辑体验上的细节：代码嵌入现在可以按目标位置打开，编辑器高亮改为跟随 Obsidian 的主题强调色，自定义等宽字体和深色主题下注释的可读性也一起修了。

从 `2.0.0` 到 `2.1.0`，仓库一共改了 28 个文件，新增 450 行，删除 81 行。这里面包含新建的 `docs/releases/` 历史归档和相关文档整理。如果不算 release 文档，剩余差异是 18 个文件，新增 147 行，删除 81 行。

---

## 1. 嵌入代码打开方式补齐

现在点击嵌入代码头部，不必只在当前 leaf 打开源文件了。

- 普通点击：仍然是在当前 leaf 中打开源文件
- `Ctrl/Cmd+Click`：在新标签页中打开源文件
- `Ctrl/Cmd+Shift+Click`：在新窗口中打开源文件
- `Ctrl/Cmd+Alt+Click`：在分栏视图中打开源文件
- 嵌入提示文案也同步更新了，中英文都会直接显示这些快捷方式

---

## 2. 编辑器高亮改为跟随主题

这次把编辑器里几处写死的高亮颜色换成了基于 Obsidian 主题变量的配色。

- 主选区现在使用基于强调色的前景色和背景色
- 活动行内的选区会再强一点，方便聚焦
- 搜索匹配和当前匹配改为基于强调色的背景、描边和阴影组合，不再使用固定的亮黄和亮红
- 同词匹配高亮也重新调了一下，保证能看见，但不会把周围代码全压住

这样在浅色、深色和自定义主题下，看起来都会顺一些。

---

## 3. 字体和深色主题可读性修复

这一版还顺手修了两处和可读性直接相关的问题。

### 自定义代码字体修复

- 等宽字体配置现在会作用到主编辑器和嵌入代码视图所使用的 CodeMirror scroller 层
- 这修复了 Obsidian 里设置的代码字体没有真正传到 Code Space 的问题

### 深色主题下注释可读性

- 深色模式下注释颜色从 `#5c6370` 调整到 `#7a8394`
- 这个调整同时覆盖主编辑器、嵌入代码渲染和相关 CSS 回退样式
