# Code Space 发布说明 - 2.0.0

## 概览
这是一个里程碑版本，让代码文件嵌入在 Obsidian 中的行为更接近原生内容。最重要的变化是全面支持通过 Obsidian 官方 **Export to PDF** 流程导出代码文件嵌入，因此嵌入代码现在会以真正的语法高亮代码块形式出现在最终 PDF 中，而不再是灰色文件卡片。本次发布还提升了更多宿主场景下的嵌入兼容性，增强了多窗口稳定性，并在原生导出路径稳定可用后移除了旧的自定义 PDF 导出方案。

## 主要功能

### 原生支持 Obsidian 的 Export to PDF
- 在桌面端使用 Obsidian 内置 **Export to PDF** 时，像 `![[script.py]]` 和 `![[robot.urdf#L20-L40]]` 这样的代码文件嵌入现在会导出为真正的语法高亮代码块。
- 实现方式接入了 Obsidian 原生打印管线，而不是再维护一套独立的 PDF 渲染流程。
- 最终 PDF 仍由 Obsidian 官方导出 UI 生成，因此官方的页面布局、分页和导出设置都能保留。

### 更广泛的代码嵌入兼容性
- 改进了代码嵌入在阅读模式、弹出窗口，以及其他复用 Obsidian Markdown 预览管线的宿主场景中的渲染表现。
- 更稳健的源路径恢复与上下文跟踪，让嵌入在视图移动、重新渲染或运行于主窗口之外时也更可靠。
- 只读嵌入视图的生命周期清理更加稳健，可减少重复渲染或窗口切换后残留视图和监听器泄漏的问题。

## 改进

### PDF 与打印管线优化
- 代码嵌入展开逻辑现在通过专门的 Markdown 转换路径共享，使导出行为更加一致。
- 在实现过程中加入了原生 PDF 诊断日志，随后收敛为 debug 级别，便于后续排查问题且不会干扰日常使用。
- 旧的自定义 PDF 导出命令和实现已移除，原生导出路径现在是主要支持方案。

### 预览与高亮一致性
- 改进了更多代码文件嵌入场景下的预览处理，包括映射语言与 XML 家族格式的语法高亮一致性。
- 进一步优化了嵌入代码样式和打印回退样式，使其在不同渲染上下文中的表现更可预测。

### 稳定性修复
- 修复了视图移动到新窗口时，可能出现的多窗口 CodeMirror 初始化问题。
- 优化了宿主切换与重复渲染期间代码嵌入的清理和重新附着行为。

## 重要说明
- 之前的自定义 PDF 导出命令已被移除。
- 如果要将嵌入代码导出为 PDF，请使用 Obsidian 官方的 **Export to PDF** 命令。
- 这个版本的发布资产应为 `main.js`、`manifest.json` 和 `styles.css`。
