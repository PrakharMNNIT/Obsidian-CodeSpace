# Code Space 发布说明 - 1.9.0

## 概览
这个版本通过语言复用映射显著扩展了语法高亮支持，新增了 R 语言支持，并修复了代码嵌入显示一致性与 URL 处理方面的重要问题。

## 新功能

### 通过语言复用扩展语法高亮
- 通过引入语言复用映射，大幅扩展了语法高亮支持范围。
- 当语言之间具备兼容性时，它们现在可以共享语法定义，减少重复，同时保持高亮准确性。
- 这种方式可以更好地支持语言变体和方言，而无需为每种变体单独维护语言包。
- **40+ 新文件扩展名** 现在支持语法高亮（可在 **Settings → Managed Extensions** 中管理）：
  - **XML 家族**：`.urdf`、`.xacro`、`.svg`、`.xsd`、`.xsl`、`.xslt`、`.wsdl`、`.plist`、`.csproj`、`.vcxproj`、`.props`、`.targets`、`.config`
  - **C/C++ 家族**：`.ino`（Arduino）、`.pde`（Processing）、`.nut`（Squirrel）、`.cu`/`.cuh`（CUDA）、`.glsl`、`.vert`/`.frag`（GLSL）、`.hlsl`、`.mm`（Objective-C++）、`.swift`
  - **Java 家族**：`.kt`/`.kts`（Kotlin）、`.scala`、`.groovy`、`.gradle`
  - **JavaScript 家族**：`.json5`、`.jsonc`、`.vue`、`.svelte`、`.astro`
  - **Python 家族**：`.pyx`、`.pxd`、`.pxi`（Cython）、`.ipy`
  - **配置文件**：`.toml`、`.ini`、`.cfg`、`.conf`（复用 YAML 高亮）
  - **Shell 脚本**：`.sh`、`.bash`、`.zsh`（Shell）、`.ps1`、`.psm1`、`.psd1`（PowerShell）
  - **其他语言**：`.cmake`、`.dockerfile`、`.diff`、`.patch`、`.lua`、`.pl`/`.pm`（Perl）、`.rb`/`.erb`（Ruby）

### R 语言支持
- 新增对 R 编程语言的原生语法高亮支持。
- R 文件（`.r`）现在可以获得正确的 token 着色与编辑器功能支持。
- 支持 R 特有的语法特征，包括赋值运算符、统计函数和数据结构。

## Bug 修复

### 代码嵌入改进
- **紧凑显示**：修复代码嵌入渲染，使其使用更紧凑的显示模式，从而获得更一致的视觉效果。
  - 将外层内边距从 12px 缩减到 4px
  - 将头部内边距从 6px/12px 调整为 4px/10px
  - 优化 CodeMirror 内容区内边距（8px 到 4px）和行内边距（0 8px 到 0 6px）
- **路径解析**：增强嵌入路径解析稳定性，避免在复杂 vault 结构中出现失效引用。
  - 当其他解析方式失败时，新增全局搜索回退逻辑
  - 会在整个 vault 中搜索匹配文件名（先精确匹配，再大小写不敏感匹配）
  - 修复从嵌套目录拖拽创建嵌入时的路径问题
- **URL 处理**：在阅读模式 URL 中保留行区间 hash，以确保导航正确。
  - 修复 `extractPathFromCandidate()`，使其保留 URL hash 片段（`#L20-L40`）
  - 行区间语法现在可在编辑模式和阅读模式中都正常工作

### 代码嵌入交互修复
- **点击行为优化**：优化点击交互，避免误跳转：
  - 只有头部标题可点击打开文件
  - 代码内容区域仅用于文本选择，不再触发跳转
  - 代码区域中的所有点击（包括 padding 区域）都会被阻止触发导航
  - 为头部新增 `user-select: none`，避免误选中文本

## UI/UX 改进
- 代码嵌入在不同上下文中的显示更加一致
- 跳转到嵌入代码片段时，视觉反馈更清晰
- 通过更紧凑的嵌入间距提升整体可读性
- 头部标题现在是打开嵌入源文件的唯一入口
