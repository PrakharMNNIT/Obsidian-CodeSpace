# Code Space 发布说明 - 1.8.0

## 概览
这个版本带来了多项提升易用性的改进：外部文件夹挂载总开关、更灵活的新建文件位置、代码嵌入的行区间语法、关闭时自动保存，以及针对嵌入渲染和代码大纲行为的重要修复。

## 新功能

### 外部文件夹挂载总开关
- 在设置中新增全局“启用外部文件夹挂载”开关。
- 关闭后，所有已挂载的外部文件夹都会被卸载（配置仍会保留）。
- 重新开启后，之前配置的挂载会自动恢复。
- 关闭时会隐藏整段外部挂载设置，使界面更简洁。

### 新建文件位置选项
- 为新建代码文件新增“当前文件所在文件夹”选项。
- 现在可以选择新建代码文件的创建位置：
  - **指定文件夹**：使用固定文件夹路径（传统行为）。
  - **当前文件所在文件夹**：保存到当前活动笔记所在的同一目录。
- 选择“当前文件所在文件夹”时，路径输入框和浏览按钮会自动隐藏。

### 代码嵌入行区间语法
- 代码嵌入现在支持行区间语法：`![[test.py#20-40]]`。
- 支持多种格式：`#20-40`、`#L20-L40`、`#L20-40`。
- 如果结束行超过文件实际长度，会自动截断到文件末尾。
- 区间模式会忽略 `maxEmbedLines` 设置，并完整显示请求的区间。
- 单行语法仍然有效：`![[test.py#20]]` 会从第 20 行显示到文件结尾。

### 关闭时自动保存
- 新增基于事件触发的自动保存机制，以防止数据丢失。
- 在以下场景中，代码文件现在会自动保存：
  - 关闭 Code Space 标签页时
  - 关闭 Obsidian 窗口时
  - 卸载插件时
- 这一机制与现有的 `Ctrl+S` 手动保存流程互补。

## Bug 修复

### 代码嵌入渲染
- 通过放宽 CSS 选择器，修复代码嵌入在阅读模式下无法渲染的问题。
- 代码嵌入现在可在 Live Preview 与 Reading 模式中正确渲染。
- 修复代码嵌入在主窗口中不显示的回归问题。

## UI/UX 改进
- 当外部挂载功能关闭时，会隐藏对应的配置区域，使设置页更简洁。
- 批量挂载/卸载外部文件夹时，通知信息更清晰。

## 部署说明
- 最低支持版本仍为 0.15.0。
- 没有破坏性变更。
- 使用外部文件夹挂载的用户会在挂载设置区顶部看到新的总开关。
