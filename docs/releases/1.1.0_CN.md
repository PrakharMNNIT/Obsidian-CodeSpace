# Code Space 发布说明 - 1.1.0

## 概览
这个版本引入了多项用于提升 Obsidian 内编码体验的重要功能，重点围绕结构化导航与界面细节优化展开。

## 新功能
- **代码大纲视图**：新增侧边栏集成，可自动解析代码符号（类、函数和方法）。支持 Python、JavaScript/TypeScript、C/C++、Java 和 PHP。
- **自定义查找与替换**：新增独立搜索面板，提供类似 VS Code 的图标化控制，支持正则表达式、大小写敏感和整词匹配。
- **悬浮搜索切换按钮**：编辑器中加入极简悬浮按钮，可快速打开搜索功能，同时避免遮挡关键 UI 区域。

## UI/UX 改进
- **仪表盘布局优化**：使用 flexbox 重构标题栏布局，确保标题与管理按钮在垂直方向上精确对齐。
- **内边距收紧**：减少工作区留白，提升文件列表与内容区域的可用空间。
- **高对比度高亮**：引入高对比度高亮方案，主选区使用浅红色，次级搜索匹配使用金黄色。
- **循环搜索**：新增搜索结果回绕支持，查找到文件末尾后可从开头继续。

## Bug 修复
- **插件生命周期**：修复重新加载插件后，侧边栏中出现重复大纲视图的严重问题。
- **弹窗关闭**：修复“创建代码文件”对话框在成功创建文件后仍然保留的问题。
- **稳定性修复**：处理多个符号解析与行跳转流程中的 `TypeError` 情况。
- **光标稳定性**：修复手动保存文件后光标回到顶部的问题。
- **代码规范**：清理全部 ESLint 警告与错误，提升稳定性并符合官方仓库标准。

## 部署说明
- 已将 `manifest.json`、`package.json` 和 `versions.json` 更新到 1.1.0。
- 所有核心发布资产（`main.js`、`manifest.json`、`styles.css`）均已重新构建并可直接分发。
