# Code Space 发布说明 - 1.2.0

## 概览
这个版本重点优化交互逻辑与编辑器稳定性。关键功能已整合进 Obsidian 原生视图头部，同时修复了搜索操作和显示对齐方面的关键问题。

## UI/UX 优化
- **原生头部集成**：将悬浮按钮替换为编辑器头部内的标准操作按钮，用于查找与大纲操作，使工作区更干净，并更符合 Obsidian 原生设计习惯。
- **智能侧边栏控制**：优化大纲激活机制，在需要时会自动聚焦当前视图并展开已折叠的右侧边栏。
- **运行/打开能力**：在头部新增“播放”按钮，触发原生“在默认应用中打开”操作，可顺畅地运行或在外部工具中编辑当前文件。
- **导航稳定性**：加入水平滚动锁定。跳转到搜索结果或代码符号时，改用 “nearest” 滚动策略，避免视口发生突兀的水平偏移。
- **行号区完整性**：为行号列设置实体背景与更高层级，防止水平滚动时代码文本在视觉上覆盖行号区域。

## Bug 修复
- **批量替换逻辑**：修复“全部替换”中的严重缺陷。此前手动偏移量计算可能导致文本损坏，现在改为使用原子事务进行可靠的批量处理。
- **图标统一**：统一界面中的符号图标风格，提供更一致的视觉引导。
- **代码质量**：清理所有悬空 Promise 与类型断言相关警告，以满足更严格的插件标准。
