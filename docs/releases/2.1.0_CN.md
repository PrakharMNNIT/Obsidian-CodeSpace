# Code Space 发布说明 - 2.1.0

## 概览

Code Space 2.1.0 重点改进编辑体验和工作区集成。代码嵌入现在可以按需要打开到当前面板、新标签页、新窗口或分屏；编辑器高亮更好地跟随 Obsidian 主题与强调色；自定义代码字体和深色主题下注释可读性的问题也已修复。

本版本不包含破坏性变更，也不需要迁移设置。

## 新功能

### 更灵活的代码嵌入打开方式

代码嵌入不再只能打开到当前面板。

- 点击嵌入标题会在当前工作区叶子中打开源文件。
- 使用 `Ctrl/Cmd+Click` 可在新标签页中打开源文件。
- 使用 `Ctrl/Cmd+Shift+Click` 可在新窗口中打开源文件。
- 使用 `Ctrl/Cmd+Alt+Click` 可在分屏中打开源文件。
- 嵌入提示文案已同步更新中英文内容，用户可以直接看到可用快捷方式。

## 改进

### 跟随主题的编辑器高亮

编辑器选区和搜索高亮现在使用 Obsidian 主题变量，而不是固定颜色。

- 主选区和活动行选区使用与强调色匹配的前景色和背景色。
- 搜索命中和当前命中使用跟随主题的背景、描边和阴影样式。
- 同词高亮保持可见，同时避免干扰主要代码内容。

这让编辑器在浅色主题、深色主题和自定义 Obsidian 主题下都更协调。

### 代码字体和深色主题可读性

- Code Space 现在会在主编辑器和代码嵌入共同使用的 CodeMirror scroller 层应用 Obsidian 的等宽字体设置。
- 深色模式下注释颜色已调整，以提高编辑器、嵌入预览和相关 CSS 兜底样式中的对比度。

## 文档

- 项目截图已移动到 `docs/img/`，英文和中文 README 已同步更新图片路径。
- `1.1.0` 至 `2.0.0` 的历史发布说明已归档到 `docs/releases/`，便于后续维护。

## 重要说明

- 本版本未移除命令、设置或数据格式。
- 发布资产仍为 `main.js`、`manifest.json` 和 `styles.css`。
