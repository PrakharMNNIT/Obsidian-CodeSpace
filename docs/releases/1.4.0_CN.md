# Code Space 发布说明 - 1.4.0

## 概览
这个版本引入了完整的国际化（i18n）系统，大幅扩展了语法高亮和大纲解析的语言支持，并进一步优化了嵌入代码块的核心交互模型。

## 国际化（i18n）
- **完整中文支持**：实现完整的 **中文（zh-CN）** 本地化。整个界面（设置、Dashboard、命令面板、通知）现在会根据 Obsidian 的语言设置自动切换。
- **本地化基础设施**：建立了稳健的翻译架构，便于后续继续扩展更多语言。

## 语言支持与解析
- **新增语法高亮**：新增对 **Rust**（`.rs`）、**Go**（`.go`）、**C#**（`.cs`）、**Java**（`.java`）、**YAML**（`.yaml`）和 **XML**（`.xml`）的支持。
- **增强版大纲解析器**：
  - **C/C++ 升级**：彻底重写解析器，以支持复杂函数签名（指针、引用、模板）以及不同缩进风格。
  - **新增语言**：大纲视图现在可准确提取 **Rust**、**Go** 和 **C#** 中的符号，并会跳过控制流关键字，让导航更干净。

## 交互增强
- **导航优化**：
  - **点击标题栏**：点击嵌入代码块的头部即可打开源文件。
  - **选择安全性**：点击代码区域内部不再触发跳转，避免在选择文本时误打开文件。同时移除了双击跳转，优先保证选择操作。
- **行号保护**：在所有视图中的行号上应用 `user-select: none`，确保拖拽复制代码时不会把行号一起复制。
