# Code Space 发布说明 - 2.2.0

## 概览

Code Space 2.2.0 重点提升代码嵌入和 Dashboard 在文件变化后的准确性。代码嵌入现在会在源文件变化后自动刷新；Dashboard 可以隐藏不希望纳入管理的文件或文件夹；TypeScript 高亮配置已修复，并新增 Kotlin 与 MATLAB 风格文件的语法高亮支持。

本版本未移除现有命令，也不需要手动迁移。

## 新功能

### 代码嵌入自动刷新

当源文件在 vault 中发生变化时，代码嵌入现在会自动更新。

- 已打开的 Markdown 预览会检查是否存在引用该变更文件的代码嵌入。
- 命中的嵌入会被重新渲染，使预览内容反映最新源文件。
- 这可以减少保存文件或由外部工具修改文件后，笔记中仍显示旧代码的情况。

### Dashboard 忽略管理

Dashboard 现在可以隐藏不希望由 Code Space 管理的文件和文件夹。

- 可通过 Dashboard 右键菜单忽略单个文件。
- 可通过 Dashboard 右键菜单忽略父文件夹，并隐藏其中的文件。
- 可通过新的 `Manage ignored files and folders` 工具栏操作查看已忽略条目。
- 忽略管理器可以直接打开被忽略的文件，也可以移除忽略项，使其重新出现在 Dashboard 中。
- 忽略路径会被规范化、去重，并在文件或文件夹重命名、删除时保持同步。

### Kotlin 与 MATLAB 风格语法支持

Code Space 新增更多语言族的语法支持。

- Kotlin 文件（`.kt`）和 Kotlin script 文件（`.kts`）使用专用 Kotlin 高亮器。
- MATLAB/Octave 风格的 `.m` 文件使用 Octave 高亮器。
- 代码嵌入和原生 Markdown/PDF 展开流程现在会将这些扩展名识别为可渲染代码文件。

## 修复与优化

### 修复 TypeScript 高亮

TypeScript 和 TSX 文件现在使用 CodeMirror 面向 TypeScript 的 JavaScript 解析配置。

- `.ts` 文件会按 TypeScript 解析，而不是按启用 JSX 的普通 JavaScript 解析。
- `.tsx` 文件会同时启用 TypeScript 和 JSX 支持。
- JavaScript、MJS 和 CJS 文件不再在不需要时启用 JSX 模式。

### 更可靠的编辑器变更检测

编辑器现在会将新文档内容与视图中已加载的文件内容进行比较，以判断内容是否变化。这样在监听 vault 文件更新时，可以更准确地获取旧内容，并减少外部变更后误判 dirty 状态的情况。

### Dashboard 相关入口的打开行为更一致

Dashboard 文件卡片和忽略管理器现在共用同一套受管文件打开路径。代码文件仍会在 Code Space 编辑器中打开；Obsidian 原生支持的文件类型仍会使用 Obsidian 原生查看器打开。

## 重要说明

- 被忽略的文件和文件夹会存储在插件数据中的新 `ignoredFiles` 设置里，默认值为空列表。
- 除非用户主动忽略文件或文件夹，否则现有 Dashboard 行为保持不变。
- Kotlin 与 MATLAB 风格高亮可用于打开和嵌入这些文件。它们不会自动加入默认受管扩展名列表；如果希望这些文件默认出现在 Dashboard 中，可以在设置里手动添加扩展名。
- 发布资产仍为 `main.js`、`manifest.json` 和 `styles.css`。
