# Code Space 发布说明 - 1.6.0

## 概览
这个版本引入了仅桌面端可用的外部文件夹挂载、更灵活的筛选能力，以及更清晰的挂载内容界面提示。同时还优化了路径显示，并新增 Windows 链接类型控制。

## 外部文件夹挂载（桌面端）
- 通过系统链接（符号链接 / junction）将外部文件夹挂载到 vault 中。
- 可在设置中管理挂载：新增、移除、重新链接与状态检查。
- 保护机制确保挂载点始终位于 vault 内部，并在出错时给出清晰反馈。
- 桌面端专属限制可避免在移动端产生兼容性问题。

## Windows 链接类型控制
- 新增链接类型设置：Auto / Symlink / Junction。
- Auto 模式会优先尝试 symlink，失败后自动回退到 junction。

## Dashboard 筛选与路径显示
- 文件夹筛选与扩展名筛选现在支持多选。
- 文件夹选择改为使用专门的弹窗，以提升长路径场景下的可用性。
- 长路径现在采用单行省略和悬浮提示展示，更清晰也更紧凑。

## 视觉提示
- 外部挂载内容现在会在 Dashboard 中显示一个低调的标记，与 vault 内文件区分开来。
