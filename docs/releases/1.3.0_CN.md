# Code Space 发布说明 - 1.3.0

## 概览
这个版本重点加固编辑器核心稳定性，并完善各平台上的视觉体验。主要改进包括为适配 macOS 而重写二进制文件处理逻辑、修复撤销历史栈的关键问题，以及让嵌入代码块与主题切换无缝同步。

## 核心修复与稳定性
- **撤销/重做逻辑修复**：修复一个严重问题，即在打开文件后立即按 `Ctrl+Z` 会清空整个文档。编辑器现在会正确地以文件内容初始化历史栈基线。
- **二进制文件兼容性**：彻底重构二进制文件（PDF、图片）的打开逻辑，修复 **macOS** 上报告的“空目录”问题，确保从 Dashboard 点击二进制文件时能稳定调用 Obsidian 原生查看器。

## 视觉与交互增强
- **主题自动同步**：嵌入代码块（`Code Embed`）现在会监听全局主题变化。在浅色与深色模式之间切换时，无需重新加载文件即可立即更新语法高亮。
- **智能侧边栏切换**：“Outline” 头部按钮现在具备真正的切换逻辑：
  - 如果侧边栏关闭，则打开。
  - 如果当前已聚焦 Outline，则折叠侧边栏。
  - 如果当前激活的是其他标签，则切换到 Outline。
- **排版升级**：
  - **字体连字**：为支持的字体（如 Fira Code、JetBrains Mono）启用连字效果，例如 `=>`。
  - **可读性**：将默认编辑器字体大小提升到 **16px**，并使用 **1.5x** 行高，提供更舒适的编码体验。
  - **一致性**：统一编辑器与嵌入视图中的字体渲染样式。
- **Gutter 细节优化**：通过强制分层与不透明背景，修复水平滚动时代码文本覆盖行号的视觉问题。
