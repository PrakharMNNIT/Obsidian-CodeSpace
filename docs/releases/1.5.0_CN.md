# Code Space 发布说明 - 1.5.0

## 概览
这个版本重点通过智能状态记忆和更顺滑的交互流程来提升用户体验。主要新增包括 Dashboard 智能记忆系统、原生文件夹选择界面，以及备受期待的编辑器排版自定义选项。

## Dashboard 持久化与稳定性
- **状态记忆**：Dashboard 现在会智能记住你的视图状态。搜索词、筛选项和排序偏好会在重新打开时自动恢复，减少重复设置。
- **智能自动保存**：加入去抖后的状态保存机制，可无感持久化变更而不影响性能。

## 交互与工作流
- **原生文件夹选择**：将原本笨重的下拉菜单替换为原生模糊搜索文件夹选择器，交互方式类似 Obsidian 的“移动文件到”弹窗，可更快速、直观地选择默认路径。
- **更流畅的创建流程**：彻底重构“创建代码文件”弹窗。
  - **内联路径切换**：在文件名输入行内直接集成路径选择按钮。
  - **即时上下文**：用户无需离开创建对话框即可随时切换目标文件夹。
  - **智能路径解析**：系统现在能正确处理如 `folder/subfolder/script.py` 这样的复杂路径，并自动创建所需目录。

## 视觉与自定义
- **字体大小控制**：新增独立的字体大小设置，分别作用于 **主编辑器**（默认：18px）和 **代码嵌入**（默认：15px），以适配不同屏幕尺寸和阅读偏好。
- **动态布局引擎**：
  - **响应式嵌入块**：代码嵌入块现在会根据配置的字体大小和行高动态计算高度，确保渲染更精确。
  - **样式隔离**：为嵌入样式补充 `!important` CSS 规则，减少第三方主题造成的冲突，保证展示一致性。
  - **紧凑默认值**：将默认嵌入行数限制调优为 20 行，使其与 Markdown 笔记的整合更紧凑。
